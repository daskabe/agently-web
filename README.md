# Agently Web

Landing site and documentation app for Agently — a Chrome extension + VS Code companion workflow for sending browser context and prompts to your IDE.

## Install Agently

- Chrome extension: https://chromewebstore.google.com/detail/agently-local-prompt-to-l/cdcngpbohinmfhnpnilaijkkdloiokcl
- VS Code extension: https://marketplace.visualstudio.com/items?itemName=bytedyno.agently-vscode-extension

## What this project contains

- Home page with product overview and install links
- Docs page with install guide, workflow walkthrough, and FAQ
- Support page with bug/feature request links and legal notes

## Local development

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```
